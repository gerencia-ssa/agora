# ÁGORA · SNSP Morelos

**Acceso a la Gestión Operativa y Rectoría Administrativa**
Portal de aplicativos y estrategias paralelas del Servicio Nacional de Salud Pública · Coordinación Estatal Morelos.

Página estática publicada con GitHub Pages. No contiene datos personales, contraseñas ni identificadores de hojas o carpetas: solo la interfaz y las ligas públicas de cada aplicativo.

## Cómo actualizar ligas, aplicativos o avisos

1. Abra `index.html` en GitHub y presione el lápiz ✏️ (*Edit this file*).
2. Con **Ctrl+F** busque la sección que necesita:
   - `CONFIGURACIÓN DE ÁGORA` → inicio de la configuración.
   - `APLICATIVOS` → tarjetas de la pestaña Aplicativos (`url`, `estado`, `acceso`).
   - `ESTRATEGIAS PARALELAS` → `estado: "vigente"` o `"cerrada"`, fechas de `inicio` y `cierre`.
   - `DESTACADOS` → carrusel de Avisos importantes (admite imagen de Google Drive).
   - `AVISOS` → panel lateral de avisos.
3. Presione **Commit changes…** → **Commit changes**. La página se actualiza sola en 1 a 2 minutos.

## Reglas del repositorio

- No subir `Code.gs`, hojas de cálculo, rúbricas, oficios ni archivos con datos personales.
- Cada cambio queda registrado en el historial (pestaña *Commits*); se puede regresar a una versión anterior.
